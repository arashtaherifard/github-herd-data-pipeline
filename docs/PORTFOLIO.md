# Portfolio Packaging

The original final-project submission includes large datasets, serialized models, MLflow artifacts, and extensive experiment-audit outputs.

The public GitHub version focuses on the reproducible implementation and final evidence:

- data collectors;
- preprocessing and feature engineering;
- database pipeline;
- model-development scripts;
- Prefect orchestration;
- MLflow registration logic;
- Docker/Kubernetes infrastructure;
- CI/CD workflows;
- figures;
- reports;
- data schemas.

Generated model binaries and local experiment stores are intentionally excluded.
